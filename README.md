# OB_TRAINING — Programming Language Learning Platform

*OB_TRAINING* is a web-based educational platform that helps users **learn programming languages** like **HTML, CSS, and PHP** while tracking their progress through *interactive quizzes*. The platform is built using **HTML, CSS, Bootstrap, PHP with PDO, SQL, sessions, and cookies**.



## Project Goals

- Teach users the fundamentals of popular programming languages.
- Provide interactive quizzes to assess understanding.
- Offer a user-friendly and responsive interface.
- Manage users securely with **login sessions and cookies** to maintain user state and protect access.

---

## Key Features

-  **User registration and login**
-  **Session and cookie-based authentication system**
-  **Courses organized by programming language**
-  **quizzes after each module**
-  **Personal dashboard for editing account information**

---

##  Technologies Used

### Frontend:
- HTML5
- CSS3
- Bootstrap 5

### Backend:
- PHP (with PDO)
- SQL / Mysql
- **Sessions and Cookies** for secure login and user tracking
- **htmlspecialchars()** used for input/output sanitization (XSS prevention)
